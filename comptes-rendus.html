Comptes rendus types

Partez d'un modèle, tapez un mot-clé : la description de la lésion apparaît et s'insère dans votre compte rendu.

  1. 1Choisissez un modèle dans la bibliothèque.
  2. 2Tapez un mot-clé, par exemple angiome : la description apparaît, Tab l'insère.
  3. 3Tab passe d'un champ [ … ] au suivant. Puis Copier ou Envoyer par e-mail.

    Aucun modèle personnel pour l'instant : écrivez ou modifiez un compte rendu puis cliquez sur Enregistrer comme modèle.

    Cliquez pour insérer à l'emplacement du curseur.

    Aucune phrase ne correspond.

      Tab insérer · ↑↓ choisir · Échap fermer

      Ouvre votre messagerie avec le compte rendu déjà rédigé : il ne reste qu'à cliquer sur « Envoyer ». L'adresse est mémorisée. E-mail ordinaire non sécurisé : pour un patient identifiable, utilisez une messagerie sécurisée de santé (MSSanté).

      Confidentialité : tout reste dans votre navigateur, le site n'envoie rien. N'y saisissez pas d'informations permettant d'identifier un patient. Les modèles sont indicatifs : adaptez-les à chaque patient, aux recommandations en vigueur et aux usages de votre service.

      À vous de programmer

      Mes phrases

      Créez vos propres descriptions : un mot-clé et un texte. Dès que vous tapez le mot-clé dans l'éditeur, votre texte vous est proposé.

      Nouvelle phrase

      Mot-clé sans espace (les accents et majuscules sont ignorés). Mettez les éléments variables entre crochets : [x] mm, [droit / gauche]. La touche Tab passera de l'un à l'autre.

      Mes phrases 0

        Aucune phrase personnelle pour l'instant. Créez-en une avec le formulaire, ou sélectionnez du texte dans l'éditeur puis cliquez sur Sélection → phrase.

        Vos phrases et vos modèles sont enregistrés dans ce navigateur. Utilisez Exporter puis Importer pour les retrouver sur un autre ordinateur.
