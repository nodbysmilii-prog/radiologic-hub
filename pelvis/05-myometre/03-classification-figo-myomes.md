# Classification FIGO des myomes

**En bref** : la classification FIGO situe chaque myome de 0 (intracavitaire pédiculé) à 7 (sous-séreux pédiculé) selon sa part dans la cavité, dans le myomètre et sous la séreuse. Elle guide le choix entre hystéroscopie, cœlioscopie ou autre traitement.

## Types

| Type | Position | Description |
| --- | --- | --- |
| 0 | Sous-muqueux | Pédiculé, intracavitaire |
| 1 | Sous-muqueux | Moins de **50 %** dans le myomètre |
| 2 | Sous-muqueux | **50 %** ou plus dans le myomètre |
| 3 | Interstitiel | Entièrement intramural, au contact de l'endomètre |
| 4 | Interstitiel | Entièrement intramural, sans contact avec l'endomètre ni la séreuse |
| 5 | Sous-séreux | **50 %** ou plus dans le myomètre |
| 6 | Sous-séreux | Moins de **50 %** dans le myomètre |
| 7 | Sous-séreux | Pédiculé |
| 8 | Autre | Cervical, parasite, autres localisations |

Un myome qui touche à la fois l'endomètre et la séreuse est noté avec **deux chiffres**, le premier pour la composante sous-muqueuse (par exemple 2-5).

## En pratique

- **Types 0, 1 et 2** : myomes sous-muqueux, accessibles à l'hystéroscopie selon leur taille et le liseré de myomètre sain (voir la fiche Léiomyome utérin).
- **Types 5, 6 et 7** : abord cœlioscopique.
- **Type 7** : risque de torsion ; diagnostic différentiel avec une masse ovarienne solide.

## Dans le compte rendu

- Pour chaque myome principal : type FIGO, taille, paroi (antérieure, postérieure, fundique, latérale), liseré de myomètre sain vers la séreuse pour les types 1 et 2.
