# Classifications des malformations génitales

**En bref** : deux classifications sont utilisées. Celle de l'**American Fertility Society (1988)** décrit sept classes d'utérus ; celle de l'**ESHRE/ESGE (2013)** code séparément l'utérus (U), le col (C) et le vagin (V).

## Classification de l'American Fertility Society (1988)

| Classe | Malformation | Sous-types |
| --- | --- | --- |
| I | Hypoplasie ou agénésie | Vaginale, cervicale, fundique, tubaire, combinée |
| II | Unicorne | Corne communicante, non communicante, sans cavité, sans corne |
| III | Didelphe | — |
| IV | Bicorne | Complet, partiel |
| V | Cloisonné | Complet, partiel |
| VI | Arqué | — |
| VII | Lié au diséthylstilbestrol (Distilbène) | — |

## Classification ESHRE/ESGE (2013)

**Utérus**

| Classe | Anomalie | Sous-classes |
| --- | --- | --- |
| U0 | Utérus normal | — |
| U1 | Utérus dysmorphique | a. en T ; b. infantile ; c. autres |
| U2 | Utérus cloisonné | a. partiel ; b. complet |
| U3 | Utérus bicorporel | a. partiel ; b. complet ; c. bicorporel cloisonné |
| U4 | Hémi-utérus | a. avec cavité rudimentaire (corne communicante ou non) ; b. sans cavité rudimentaire |
| U5 | Aplasique | a. avec cavité rudimentaire ; b. sans cavité rudimentaire |
| U6 | Malformation non classée | — |

**Col et vagin**

| Code | Col | Code | Vagin |
| --- | --- | --- | --- |
| C0 | Col normal | V0 | Vagin normal |
| C1 | Col cloisonné | V1 | Cloison vaginale longitudinale non obstructive |
| C2 | Deux cols « normaux » | V2 | Cloison vaginale longitudinale obstructive |
| C3 | Aplasie cervicale unilatérale | V3 | Cloison vaginale transverse et/ou imperforation hyménéale |
| C4 | Aplasie cervicale | V4 | Aplasie vaginale |

Exemple : un utérus cloisonné complet avec col cloisonné et vagin normal se code **U2b C1 V0**.

## Correspondances utiles

| AFS | ESHRE/ESGE |
| --- | --- |
| Unicorne (II) | Hémi-utérus (U4) |
| Didelphe (III), bicorne (IV) | Bicorporel (U3) |
| Cloisonné (V) | Cloisonné (U2) |
| Agénésie (I) | Aplasique (U5) |
| Lié au Distilbène (VII) | Dysmorphique en T (U1a) |
